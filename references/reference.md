# 基金申报书撰写参考手册

本文件为 `grant-application-iterative-drafting` 技能的辅助参考，沉淀自省基金申报书实战（2026-08）。包含三文件体例模板、模拟评审分级检查清单、指标软化与对照设计原则、三文件口径一致性检查表。

## 一、三文件体例模板

### 1. 立项依据（研究论证核心，通常字数最多）

| 节 | 内容要点 | 写作提示 |
|----|----------|----------|
| 项目名称（暂定） | 压缩版名称，≤35字为宜 | 删冗余限定词（产地、方法细节等属性正文展开即可），自造复合词（如"协效组装"）需在正文首次出现处给出定义 |
| 研究意义 | 疾病/产业背景 → 科学价值 | 结尾给出项目核心思路一句话 |
| 现状分析 | 分节综述（（一）机制主线（二）活性成分（三）组装载体…），每节末尾落研究不足 | 以[编号]引用文献；综述中他人实验数值（IC50等）属于文献引述，不属于承诺 |
| 研究不足 | 逐条列出空白，每条给出化学/生物学依据 | "尚无研究系统考察X"句式；给出为什么本研究体系具备可验证性 |
| 科学问题 | 每个科学问题一段，加粗，括注对应现状分析哪节空白 | 问题必须是提问而非承诺；括注内写"以严格对照组设计实证X" |
| 前期基础/研究基础 | （一）预实验数据（二）课题组积累（三）方法学可迁移性 | 预实验数据要能支撑关键假设，方法学基础写"有基础、非从零起步" |

### 2. 项目概述（实施设计核心，体现"怎么干"）

| 节 | 内容要点 | 写作提示 |
|----|----------|----------|
| 目标任务 | 可数化的过程/产出类指标 | 只写过程/产出指标（如"获得3种结构差异化组分"），不写无法保证的结论性指标 |
| 研究内容 | 按科学维度简明分述（3-5条） | 讲"做什么、科学维度"，不写操作参数 |
| 实施方案 | 按研究内容分述，操作细节级 | 写操作参数（溶剂、温度、时间、剂量、分组）、对照组设置、判定标准 |
| 技术关键 | 5-8条 | 每条=挑战+对策；包括统计效力保障、关键参数测定、风险控制 |
| 技术路线 | 一段式流程图描述（文字稿） | 与实施方案完全一致，后续可图形化 |
| 年度工作安排 | 按月/季度分条 | 跨年度任务注明衔接关系 |
| 预期成果 | 论文/专利/人才培养 | 与目标任务口径一致 |

### 3. 研究基础（前期积累展示）

| 节 | 内容要点 |
|----|----------|
| 前期研究积累 | 预实验数据表、已有结果（附图/表）、代表性论文 |
| 实验条件 | 平台、设备、基地、合作单位 |
| 方法学基础 | 关键技术能力（结构表征、活性筛选、数据分析） |

## 二、模拟评审分级检查清单

评审视角通读后按严重度分级，各级别检查项示例：

### P0（硬伤/原则性问题，不整改必毙）
- [ ] 多文件术语口径不统一（如"修饰"vs"分级提取"），且与预实验事实冲突
- [ ] 核心命题无对照组设计（如声称"组装优于混合"却没有物理混合物组）
- [ ] 关键验证环节缺失（如声称体内增效却无药代/暴露证据）
- [ ] 科学问题与实验设计不呼应（立项依据提问、概述不给解法）
- [ ] 项目名称与正文核心思路不一致

### P1（实质修改，影响评审打分）
- [ ] 承诺性硬指标无法兑现（如小样本撑不起的建模鉴定结论）
- [ ] 统计效力不足且无依据（样本量、入组标准、变异预案）
- [ ] 判定标准与方法学不匹配（如把CI法用到动物组间比较）
- [ ] 对照组缺失导致主张无法归因
- [ ] 新增设计（如药代、机制检测）未同步更新技术路线/年度安排/研究内容

### P2（文字收尾，定稿阶段处理）
- [ ] 错别字（专业名词：阿卡波格→阿卡波糖类）
- [ ] 参考文献编号不连续、正文引用与文献表不对应
- [ ] 项目名称过长或各文件不一致
- [ ] 冗长段落可压缩（如中医理论段压1/3）
- [ ] 技术路线框图/机制示意图缺失或过时

### 评级参考
B+：P0清零、P1大部分处理、P2遗留可收尾 → 可提交；B以下：存在P0未处理。

## 三、指标软化与对照设计原则

### 指标软化操作实例（省基金实战）
| 原文（硬承诺） | 软化后 |
|----------------|--------|
| "建立构效关系模型（PLS/PCA）" | "探索性关联分析而非预测性模型构建；逐级相关分析为主，PLS/PCA为辅助，VIP排序仅报告不判定" |
| "动物水平显著优于组分加和效应" | "加和效应以CI法仅在酶/细胞水平判定；动物水平以组装体vs物理混合物组间检验为主" |
| 5组×6只 | 6组×8只（新增游离多糖组评价君药体内单独贡献；n=8为中等效应量最低可检配置，写明依据） |

要点：**文献引述的数值（他人IC50等）保留；本申请承诺的量化结果软化。** 软化不是删掉，而是降格定位+给弹性出口（"若趋势明确，结题前补验证性小实验"）。

### 对照设计三原则
1. 核心命题有对照组闭环：效应主张→组间比较；机制主张→机制差异
2. 每个主张各有证据闭环，两个主张可用一个三方对比设计同时覆盖（组装体vs混合物vs模型）
3. 设计回应评审最可能质疑的点（如"物理混合物口服后原位自发组装稀释优势"→简化药代比较暴露差异）

## 四、三文件口径一致性检查表

| 检查项 | 立项依据 | 项目概述 | 研究基础 | 处理 |
|--------|----------|----------|----------|------|
| 项目名称 | Vn名称 | Vn名称 | 引用处 | 压缩版名称全文件统一 |
| 术语口径 | pH梯度分级提取 | 同左 | 同左 | 与预实验事实一致，禁止"修饰/后处理"残留 |
| 判定标准 | 科学问题二表述 | 动物判定口径 | 预实验数据 | 提问↔解法呼应（如"体内暴露优势"↔"简化药代评价"） |
| 参考文献编号 | [1]-[50]连续 | 引用编号 | 引用编号 | 同一文献三文件编号一致 |
| 承诺性指标 | 提问中性化 | 承诺软化 | 引述保留 | 逐段检查强承诺词 |
| 待补标记 | 【待补】清单 | 【待补】清单 | 【待补】清单 | 收尾统一汇总 |

### 编号重排操作规范（sed）
1. 先备份：范围引用保护（如 `[17-22]` → 临时占位符）
2. 必须**从大到小**替换：先 `[49]→[50]` 再 `[48]→[49]`，防止链式冲突
3. 插入新文献（如 [11a]→[12]）后，逐条核验表格行与正文引用对应关系
4. 复合引用（如 [46-48]）与范围引用同步更新
5. 终检：`grep -o '\[[0-9]*\]' | sort -t'[' -k2 -n | uniq -c` 检查连续性
